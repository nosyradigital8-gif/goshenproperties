# Goshen Properties homepage plan

Build one responsive Next.js App Router homepage with a premium real-estate editorial direction. The page includes sticky navigation, a hero, company introduction, category showcases for modern homes, prime lands and secure investment, a suggested discovery journey, contact CTA and footer. All links remain on-page or open verified WhatsApp, telephone and email actions.

The repository supplied only a 200px Goshen logo image, so the logo is preserved in original, transparent, favicon and full white-background variants. Three representative editorial visuals were created for the homepage because no property photographs were present. They are explicitly described in the interface as category imagery rather than verified live listings; no prices, addresses, measurements, availability or guarantees are invented.

The palette follows the logo’s deep navy, royal blue and green identity. `app/page.tsx` contains the homepage, `app/components/mobile-nav.tsx` contains the only client interaction, `app/globals.css` contains the responsive visual system, and `public/images/` contains organized brand and editorial assets.
